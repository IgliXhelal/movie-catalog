# Movie Catalog

A movie catalog built with HTML, CSS, and JavaScript. Search by title or director, filter by genre, or use Manage to add, edit, and delete movies. Changes are saved in the browser.

## Project files

- `index.html` contains the catalog, management table, and movie forms.
- `styles.css` is the CSS library for the layout, movie cards, and forms.
- `movie-library.js` handles validation, search, statistics, and browser storage.
- `app.js` connects the page controls to the JavaScript library.
- `movies.js` contains the starter collection of 20 movies.

## Run locally

Open the folder in VS Code, right-click `index.html`, and select **Open with Live Server**.
